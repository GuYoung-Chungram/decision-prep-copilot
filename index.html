Part 1 · 실습

사례 하나를 골라 6단계를 직접 채워보세요

각 단계는 완료 기준을 채우고 검토·확정에 체크해야 다음으로 넘어갑니다. 실제 에이전트도 같은 규칙으로 동작합니다.

  • 이 페이지는 AI를 호출하지 않고 서버로 아무것도 보내지 않습니다. 입력값은 지금 쓰는 브라우저에만 저장됩니다.
  • 그래도 실제 고객명·사내 수치·인사 정보는 넣지 마세요. 실제 업무는 사내 Copilot에서 다룹니다.

    결정 준비 자료 (초안)

    검토 후 직접 SharePoint 또는 OneNote에 기록하세요. 자동 저장·발송은 하지 않습니다.

    
          
    
        
    
      
    
    
    

    
    
      
    
        
    Part 2 · 내부망 구축
    
        
    사내 Microsoft 365 Copilot에서 직접 만들기
    
        
    보안을 위해 실제 에이전트는 각자 회사 계정 안에서 만듭니다. 아래 지침을 복사해 붙여 넣으면 실습과 같은 6단계 흐름으로 동작합니다.
    

        
    
          
      
            
    1. Copilot 앱에서 에이전트 만들기
      회사 계정으로 Microsoft 365 Copilot에 들어가 에이전트 만들기(Agent Builder)를 엽니다. 메뉴 이름은 테넌트·버전에 따라 다를 수 있습니다.
      2. 
            
    2. 이름·설명 입력
      이름: 결정 준비 코파일럿
      설명: 불확실한 업무 상황을 결정 문제·정보 상태·옵션·에스컬레이션 초안으로 정리합니다. 결정은 사용자가 합니다.
      3. 
            
    3. 지침 붙여 넣기
      '지침 복사' 버튼으로 전체를 복사해 '지침(Instructions)' 칸에 붙여 넣습니다.
      4. 
            
    4. 지식원은 최소로
      승인선·SOP·담당자 문서가 있는 SharePoint 위치만 연결합니다. 직원·리더 평가 자료가 있는 위치는 연결하지 않습니다. 문서마다 최신 기준과 소유자를 먼저 정하세요.
      5. 
            
    5. 시작 프롬프트 등록
      아래 예시 4개를 시작 프롬프트로 넣습니다.
      6. 
            
    6. 실제 사례로 테스트 후 공유
      자기 업무 사례 2~3건으로 돌려보고 체크리스트를 통과하면 팀에 공유합니다.
      7.

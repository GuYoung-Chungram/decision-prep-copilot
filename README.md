# 결정 준비 코파일럿 실습

불확실한 업무 상황을 6단계(상황 캡처 → 정보 구분 → 비용 판단 → 옵션 구성 → 에스컬레이션 → 결정 기록)로 정리하는 연습 페이지입니다.

- **Part 1 · 실습**: 가상 사례 3개(또는 직접 입력)로 6단계를 채웁니다. 단계마다 완료 기준을 채우고 '검토·확정'해야 다음으로 넘어갑니다.
- **Part 2 · 내부망 구축**: 사내 Microsoft 365 Copilot에서 같은 에이전트를 만드는 순서, 붙여 넣을 지침, 시작 프롬프트, 테스트 체크리스트.

## 보안

- AI·서버 호출이 없는 정적 페이지입니다. 입력값은 사용하는 브라우저의 localStorage에만 저장됩니다.
- 사례는 모두 가상입니다. 실제 업무 정보는 이 페이지가 아니라 사내 Copilot에서 다룹니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면·스타일 |
| `app.js` | 6단계 위저드 로직 |
| `cases.js` | 실습용 가상 사례와 예시 답안 |
| `copilot-instructions.js` | Copilot 에이전트 '지침' 원문 |
| `qr.png` | 이 페이지로 들어오는 QR |
